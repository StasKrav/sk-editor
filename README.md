# Stankrav-Edit

Браузерный редактор кода с деревом файлов, оглавлением (TOC) и подсветкой синтаксиса.

## Возможности

- **Файловый менеджер**: навигация с клавиатуры, создание, удаление, переименование, копирование.
- **Оглавление (TOC)**: список функций, классов, методов, селекторов — с переходом по клику.
- **Подсветка синтаксиса** для JavaScript, TypeScript, CSS, HTML.
- **Форматирование** через Prettier (Ctrl+Shift+F).
- **Две темы**: Zenburn (тёмная) и Solarized Light (светлая).
- **Вкладки** с сохранением состояния каждой (позиция курсора, undo-история).

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+S` | Сохранить |
| `Ctrl+Shift+S` | Сохранить как |
| `Ctrl+Shift+F` | Форматировать |
| `Ctrl+N` | Новая вкладка |
| `Ctrl+O` | Открыть папку |
| `Alt+O` | Открыть файл |
| `Alt+N` | Создать файл |
| `Alt+M` | Создать папку |
| `Ctrl+Q` | Закрыть вкладку |
| `Ctrl+1..9` | Переход на N-ю вкладку |
| `Ctrl+PageUp/Down` | Переключение вкладок |
| `Alt+1` | Тумблер: дерево ↔ редактор |
| `Alt+2` | Тумблер: TOC ↔ редактор |
| `Delete` | Удалить файл (в дереве) |
| `F2` | Переименовать (в дереве) |
| `Ctrl+D` | Дублировать (в дереве) |
